# Samples

## Purpose

Represent physical units moving through the stability workflow.

## Lifecycle

Created -> Stored -> Scheduled -> Pulled -> Received -> Testing -> Completed -> Archived.

## Traceability

Every sample must be traceable to:
- organization
- site
- study
- batch
- timepoint
- storage location
- custody events

## Custody events

Record:
- who
- when
- source location
- destination location
- quantity
- reason where relevant

## Rules

Never silently change the chain of custody.
Corrections create new history.
