# Protocols

## Purpose

A Protocol is the stable identity of an approved stability-testing plan. Executable content is stored in ProtocolVersion.

## Protocol contents

A protocol version may define:
- study type
- timepoints
- storage conditions
- sample requirements
- tests
- acceptance criteria references
- scheduling rules

## Rules

- draft versions may be edited
- approved versions are immutable
- a new change requires a new version
- old studies continue referencing their original version

## Acceptance criteria

The same protocol can have multiple versions while historical studies remain reproducible.
