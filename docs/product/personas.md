# Personas

| Persona | Primary goal | Key controls |
| --- | --- | --- |
| Organization owner/admin | Configure organization, sites, users and access; manage subscription | tenant administration; cannot bypass quality controls |
| QA manager | Approve controlled definitions, review results, investigate exceptions and inspect audit evidence | separation of duties, signature evidence, read-only audit history |
| Supervisor | Coordinate laboratory work and review submissions | assigned study/site scope; workflow-limited review authority |
| Analyst | Pull samples, enter attributable results and resolve tasks | only assigned/scope-authorized records; cannot approve restricted work |
| Executive/read-only user | See operational risk and reporting | read-only aggregate/detail access within membership scope |
| Service account/integration | Exchange approved data through API/webhook | narrow scopes, rotation, audit and tenant binding |
