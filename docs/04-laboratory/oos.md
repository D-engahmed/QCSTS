# Out-of-Specification (OOS)

## Trigger

A result evaluates outside its approved acceptance criteria or a defined laboratory rule identifies an OOS condition.

## Lifecycle

Detected -> Open -> Investigation -> QA Review -> Closed.

## Requirements

- linked result
- linked specification version
- description
- owner
- severity
- investigation record
- root cause where determined
- corrective/preventive action reference where applicable
- approvals
- complete audit trail

Do not overwrite the underlying result to make the OOS disappear.
