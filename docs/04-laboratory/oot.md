# Out-of-Trend (OOT)

## Purpose

Capture results that are within specification but show a potentially significant trend or unexpected behavior.

## Initial implementation

Provide controlled OOT records and a manual QA workflow before automated statistical detection is introduced.

## Future analytics

Trend detection may later use statistical methods, but the model must retain:
- source results
- analysis method/version
- thresholds
- generated alert
- human disposition

AI must not silently classify regulated results.
