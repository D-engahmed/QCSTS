# Deviations

## Purpose

Track unexpected events affecting study execution, laboratory work or controlled processes.

## Lifecycle

Draft -> Open -> Investigation -> CAPA/Disposition -> QA Review -> Closed.

## Fields

- deviation_id
- organization/site
- impacted study/batch/sample/result
- description
- severity
- owner
- due date
- investigation
- root cause
- action plan
- approvals
- closure evidence

## Rules

Deviation history is append-only. Closure requires explicit authorization and evidence.
