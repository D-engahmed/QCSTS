# QCSTS IQ/OQ/PQ Evidence Framework

## IQ — Installation Qualification
Verify image/version, infrastructure configuration, environment variables, database/cache connectivity, TLS/reverse proxy configuration, and backup destination.

## OQ — Operational Qualification
Verify authentication, RBAC, tenant isolation, CRUD, controlled transitions, electronic signatures, audit immutability, billing entitlement enforcement, scheduled jobs, and backup/restore.

## PQ — Performance and Process Qualification
Verify customer-approved end-to-end stability study execution, result review/approval, quality-event linkage, reporting, notifications, and representative operational load.

These templates require execution evidence in the target environment.
